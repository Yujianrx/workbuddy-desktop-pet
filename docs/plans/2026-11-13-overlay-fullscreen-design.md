# 置顶、全屏收起与短胶囊

用户确认：桌宠和胶囊独立选择置顶；全屏时两者一起隐藏，退出后恢复之前的显示模式；胶囊会话区域由200缩至150逻辑像素。

默认保持置顶，并启用全屏自动收起。设置与右键显示菜单提供三个开关，选择持久保存。胶囊置顶同时控制同一窗口的常驻窗口／完整看板。自动收起独立于手动显隐，不修改人物选择、显示模式、坐标或授权。恢复不抢焦点，不把手动隐藏的人物或整组重新显示。

检测前台窗口客户区是否覆盖所在显示器，支持负坐标副屏；结合Windows报告的独占全屏游戏和演示状态。排除桌面、任务栏、自身窗口和普通最大化窗口；普通窗口化游戏不按进程名称猜测。每500ms检查，进入立即隐藏，连续两次非全屏后恢复；检测失败保留当前状态。自动隐藏时暂停角色解码，任务继续接收；提醒及自动更新对话框等到恢复后显示。

缩短会话文本区域，保留字号、粗体积分和点击区域；长标题省略，提示保留全文。极简圆形积分和常驻窗口尺寸保持原规格。验证置顶切换、全屏退出、手动显隐、三种配色、长标题／积分、窗口模式与隐藏后拖动状态；原生独立测试窗口验证真实Windows全屏与置顶，不宣称每种游戏均经过实测。

参考Windows官方API说明：SHQueryUserNotificationState（shellapi）、GetClientRect／ClientToScreen／GetMonitorInfo（winuser）。不收集窗口标题、聊天内容或游戏进程参数。
