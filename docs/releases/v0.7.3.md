# WorkBuddy Desktop Pet v0.7.3

更适合日常办公和全屏游戏的桌面显示。

- **分别设置置顶**：右键“显示”或设置页，独立开关桌宠置顶、胶囊／窗口置顶，重启后保留。
- **全屏自动收起**：默认在前台全屏游戏、无边框全屏及全屏应用中一起隐藏桌宠和胶囊，退出后恢复原来的显示方式和人物显隐，不抢焦点。普通最大化、普通窗口化游戏不触发；可自行关闭此功能。
- **胶囊更短**：会话区从200缩为150逻辑像素；长任务标题省略，悬停可看全文，积分保持完整粗体显示。
- **保留使用习惯**：五种显示方式、三色主题、透明底、角色选择、导入素材和现有授权保留。全屏期间暂停人物动画，延后任务通知及更新弹窗；已打开的看板页面不会因自动收起而切走。

下载 `workbuddy-desktop-pet-0.7.3-windows-x64-setup.exe` 安装升级，另提供ZIP便携包和SHA256校验文件。旧程序回退目录继续保留。

原生Windows验证覆盖100%／150%缩放、独立置顶、普通最大化与全屏切换、无焦点抢占恢复、窗口模式和手动隐藏保留。自动回归、冻结程序和Windows安装升级卸载检查作为正式发布门禁；测试数据均为合成数据，角色GIF未改动。
